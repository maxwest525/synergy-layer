# Execution Handbook Topic Map

> AOOS observes first, diagnoses second, proposes only when evidence is sufficient, executes only an approved snapshot, and measures without inventing causality.

## Lifecycle

`evidence -> finding -> diagnosis -> proposal -> validation -> approval -> execution -> rendered proof -> outcome comparison -> knowledge review`

## Contract groups

- Governance: [Source of Truth](SOURCE_OF_TRUTH.md), [Tenancy and Permissions](TENANCY_PERMISSIONS.md), [Brand and Claims](BRAND_AND_CLAIMS.md)
- Decisioning: [Detection Rules](DETECTION_RULES.md), [Diagnosis and Remedy Matrix](DIAGNOSIS_REMEDY_MATRIX.md), [Evidence Policy](EVIDENCE_POLICY.md)
- Delivery: [Proposal Data Contract](PROPOSAL_DATA_CONTRACT.md), [Validation Gates](VALIDATION_GATES.md), [Execution and Rollback](EXECUTION_ROLLBACK.md)

- Scope: [Component Registry](COMPONENT_REGISTRY.md), [Site, Page, and Keyword Map](SITE_PAGE_KEYWORD_MAP.md)

## Non-negotiable boundary

A finding is evidence that something was observed. Approval is permission for one concrete, versioned action. They are never the same record state or user action.
